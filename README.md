# DiplomaFlow

Микросервисная платформа для управления дипломными проектами.

## 📋 Требования

- **Go** 1.25
- **Docker** и **Docker Compose**
- **Make** (для Windows: через Git Bash или WSL)
- **Protocol Buffers** compiler (`protoc`)
